Overview

The TOC Service generates clickable PDF tables of contents. Upload your PDF files and receive a single merged document with a professional table of contents page prepended. The TOC entries link directly to the corresponding pages in the final PDF.

Mode A: Upload Multiple PDFs

Upload multiple PDF files at once. The service merges them into a single PDF and prepends a table of contents page. Each uploaded file becomes one TOC entry, using the filename (without .pdf) as the entry title.

Options

  • Title — displayed at the top of the TOC page (optional)
  • Subtitle — displayed below the title (optional)
  • Font — choose between IBM Plex Sans, Inter, or Roboto
  • Line color — color of the decorative bars; pick a preset or enter a custom hex code
  • Background color — background color of the TOC page; pick a preset or enter a custom hex code
  • Font color — text color on the TOC page; pick a preset or enter a custom hex code
  • Dot leaders — dotted line between entry name and page number
  • Section lines — decorative bars above and below the TOC
  • Merge only — merge PDFs without adding a visible TOC page

Mode B: Existing PDF + JSON

Upload a single PDF together with a JSON file that defines the TOC entries. The service generates a TOC page and prepends it to the existing PDF. This mode is useful when you already have a merged document and want to add a table of contents.

Options

Same options as Mode A (title, subtitle, font, line color, background color, dot leaders, section lines) except merge-only.

JSON Format

The JSON file must contain an array of objects. Each object represents one TOC entry. 

[
  {
    "title": "Chapter 1 — Introduction",
    "page": 1,
    "pages": 5
  },
  {
    "title": "Chapter 2 — Methods",
    "page": 6,
    "pages": 12
  },
  {
    "title": "Appendix",
    "page": 18
  }
]

Fields

  • title (string, required) — display name of the TOC entry
  • page (integer, required) — page number in the original PDF where this entry starts
  • pages (integer, optional) — number of pages for this entry (displayed as page range in the TOC)

Options Reference

Font

IBM Plex Sans (default), Inter, or Roboto. Applied to the entire TOC page.

Line Color

Color of the decorative bars above and below the TOC. Choose from preset colors or enter a custom hex code (e.g. #FF5733).

Background Color

Background color of the TOC page. White by default. Choose from preset colors or enter a custom hex code.

Font Color

Text color on the TOC page. Black by default. Choose from preset colors or enter a custom hex code.

Dot Leaders

When enabled, a dotted line connects each entry title to its page number. Enabled by default.

Section Lines

Decorative colored bars rendered above and below the table of contents. Enabled by default.
